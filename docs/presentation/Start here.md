## Present now

For a ready-to-present deck, open **OCD Brilliance — Presentation.html** from this folder in your browser. Use **← / →** to change slides and **F** for fullscreen. It works offline with the local Screenshots folder. Use the presenter guide on a second screen or your phone.

For native Obsidian slides, open the Markdown presentation. If needed, enable **Settings → Core plugins → Slides**, then run **Start presentation** from the command palette. Slides is currently disabled in this vault; no existing plugin settings were changed.

For a normal reading view, open the Markdown presentation and switch to Reading view. All screenshots are embedded inside this vault.
